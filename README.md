# HSI Studio — Releases

Public download & auto-update feed for **HSI Studio Desktop**.

This repository contains only build artifacts (installers and update metadata).
The application source code lives in a separate private repository.

## Install

Grab the latest `hsi-studio-Setup-<version>.exe` from the
[Releases](https://github.com/wiki-virus/hsi-studio-releases/releases) page.

Installed copies check this feed on launch and update themselves automatically.
